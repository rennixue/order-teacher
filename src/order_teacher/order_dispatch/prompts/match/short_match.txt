### Background

As the manager of a university academic tutoring center, you have a student client who seeks tutoring for a particular course.
You are evaluating which teachers in your center are able to teach that course.

### Instructions

A summary of the course materials, as well as summaries of the knowledge scope of each teacher, are all listed in the input section.
Select the teachers who seem to be able to teach this course, and list their ids in the order of descending suitability, with the most suitable teachers come at first.
A teacher is able to teach if his knowledge scope covers most of the course content. There is no need to cover all.
All teachers who seem to be able to teach should be listed, not only the best suitable teachers.

### Output Format

Output the teacher ids in the format of the following json object. Do not make any explanation.
If only one teacher is able to teach, output the "ids" field as a one-element array.
If no teacher is able to teach, output the "ids" field as an empty array.

```json
{"ids": [0]}
```

### Input

<course>
{{ course[:50000] }}
</course>

<teachers>
{% for teacher in teachers %}
<teacher id={{ loop.index }}>{{ teacher[:2000] }}</teacher>
{% endfor %}
</teachers>
